# LESBIANADE®

> FUEL THE UPRISING.™

The world's leading lesbian hydration technology company.

## About

LESBIANADE® is a fictional sports hydration brand established in 1967 on the Greek island of Lesbos.

This website is a satirical recreation of a modern multinational beverage company's online presence.

## Technology

- SvelteKit
- Svelte 5
- Vite
- CSS
- JavaScript

## Setup:
Clone the repo:
```bash
git clone https://github.com/OWelton-Rosie/LESBIANADE.com && cd LESBIANADE.com
```

Install the dependencies:
```bash
npm install
```

Run the app
```bash
npm run dev
```

Navigate to [localhost:5173](localhost:5173).
