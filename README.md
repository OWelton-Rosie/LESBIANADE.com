# LESBIANADE®

> FUEL THE UPRISING™

A fictional beverage brand combining contemporary sports hydration with satirical corporate storytelling.

## About

LESBIANADE® is a fictional sports hydration brand established in 1967 on the Greek island of Lesbos.

This website is a satirical recreation of a modern multinational beverage company's online presence.

## Project Origin

LESBIANADE® began as a playful wordplay concept inspired by women's sport and familiar sports-drink branding. The idea grew into a satirical branding and web-development project exploring how consumer brands present themselves online—and how even a fictional beverage company can acquire an impressively straight-faced corporate identity.

The site combines visual branding, product storytelling, corporate-style communications, and tongue-in-cheek institutional language. It is also a practical exercise in frontend development, visual design, content strategy, and maintaining a cohesive identity across a multi-page website.

**Fictional brand. Real code. Excessive corporate synergy.**

## Setup

Clone the repo:

```bash
git clone https://github.com/OWelton-Rosie/LESBIANADE.com && cd LESBIANADE.com
```

Install the dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```

Navigate to [localhost:5173](http://localhost:5173).
