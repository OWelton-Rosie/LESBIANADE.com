# LESBIANADE®

> FUEL THE UPRISING™

A fictional beverage brand combining contemporary sports hydration with satirical corporate storytelling.

## About

LESBIANADE® is a fictional sports hydration brand established in 1967 on the Greek island of Lesbos.

This website is a satirical recreation of a modern multinational beverage company's online presence.

All images on the site are generated by DALL-E 3.

## Technology

- SvelteKit
- Svelte 5
- Vite
- CSS
- JavaScript

## Setup

Clone the repo:

```bash
git clone https://github.com/OWelton-Rosie/LESBIANADE.com && cd LESBIANADE.com
```

Install the dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```

Navigate to [localhost:5173](http://localhost:5173).
